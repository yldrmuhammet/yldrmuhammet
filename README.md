## / About Me

I work at the intersection of **mechanical engineering, quality management, battery manufacturing and software development**. My focus is to build practical systems that connect shop-floor operations with structured data, traceability and actionable quality insights.

- **Engineering:** Battery packs, production processes, process optimization, technical documentation and test methods.
- **Quality:** ISO 9001, AS9100D, ISO 14001, ISO 45001, audits, root-cause analysis, CAPA, FMEA, SPC and measurement systems.
- **Digitalization:** Manufacturing execution concepts, serial-number traceability, quality-control applications, reporting and workflow automation.
- **Software:** Desktop, web and mobile solutions that support engineering and industrial operations.

> **My approach:** Design with engineering discipline. Validate with data. Improve through continuous feedback.
